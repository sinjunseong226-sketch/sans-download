# sans-download
사용 방법⬇️
1.sans 폴더를 연다.
2.Microsoft Defender del.bat을 관리자 권한으로 실행한다.
3.sans.zip의 압축을 풀고 안에 있는 sans.exe를 실행한다. (폴더 안에 있는 파일을 옮겨서는 안된다.)

⚠️가상머신에서 실행 하세요. 물론 복구 방법도 있습니다. 

1.Hirens boot cd로 부팅 한다.
2. win+R (c:\windows\system32)
3.ntoskrnl.exe.bak를 한번 클릭한다 그리고 f2를 누르고 ntoskrnl.exe로 바꾼다.
4.재부팅 한다.
5.윈도우에 진입 하고 sans.zip에 있는 taskmgr.reg 파일을 실행한다.
6.재부팅 한다.

특이점: windows 8.x는 알아서 복구 한다.
